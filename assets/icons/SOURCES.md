# Icon sources

This file lists the source of each icon file.

- "Copied" means the file is the source file, byte for byte.
- "Traced" means our tool traced the reference into a single-color SVG. The SVG uses `fill="currentColor"`.
- "Drawn" means we drew the SVG by hand. The SVG uses `currentColor`.
- The `_refs/` folder holds the reference images. The user decides later if the repo keeps them.
- The tracer is a scratch Go program. It uses github.com/dennwc/gotrace (a Go port of potrace). It is not in this repo.
